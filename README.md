# E-Commerce Final 🛍️

Este es un proyecto de tienda en línea para calzado masculino, construido con **HTML, CSS y JavaScript** como parte de un ejercicio práctico.

## 🚀 Características

- Catálogo de productos con imágenes y descripciones.
- Interfaz responsiva y amigable.
- Estilos personalizados inspirados en los colores del Junior de Barranquilla.

## 📁 Estructura

```
Ecomerce_Final/
├── index.html
├── style.css
├── script.js
├── img/
└── productos/
```

## 🔧 Instalación

1. Clona el repositorio:

```bash
git clone https://github.com/guacharako23/Ecomerce_Final.git
cd Ecomerce_Final
```

2. Abre `index.html` en tu navegador.
